# Tokens

Design tokens are CSS custom properties in `src/styles/tokens.css`. Everything on this page is read from that file, so it always shows the values the app uses. Components reference tokens with `var(--token)` and never hard-code colours, spacing or font sizes. Rationale: `context/design-direction.md`.
